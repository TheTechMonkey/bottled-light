# Bottled Light

A Fabric mod that lets you craft and place invisible light sources. Hold Bottled Light to see nearby placed lights sparkle, and use water bottles to dim or remove them.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API 0.161.0+26.3 or newer
- Java 25

## Building

Run `./gradlew build` on macOS/Linux or `gradlew.bat build` on Windows. The playable mod JAR is created in `build/libs`.
